## 🧠 MEMORY TECHNIQUES

### **1. Association Method**
Connect new concepts to things you already know:
- **Primary Index** = Like a book's table of contents (orders the book)
- **Foreign Key** = Like a reference in a book (points to another page)
- **Transaction** = Like a bank transfer (all steps succeed or all fail)

### **2. Acronym Method**
Create acronyms for lists:
- **ACID** = All-or-nothing, Consistent, Independent, Durable
- **DDL/DML/DCL/TCL** = Define, Manipulate, Control, Transaction

### **3. Visualization Method**
Draw diagrams in your mind:
- Three Schema Architecture = Three layers (External → Logical → Physical)
- B+ Tree = Tree with data only in leaves (like a real tree with fruits only at branches)

### **4. Story Method**
Create stories:
- "A **Super Key** is like a person with many IDs (driver's license, passport, etc.) - any one works, but some are bigger than needed. A **Candidate Key** is like choosing the best ID (minimal but still works). The **Primary Key** is the one you actually use."

### **5. Repetition Method**
- Read → Write → Recite → Review
- Say answers out loud
- Teach someone else (even if imaginary)

## 💡 REMEMBER THESE GOLDEN RULES

### **Rule 1: Three Levels**
- External = User sees
- Logical = What is stored
- Physical = How stored

### **Rule 2: Keys Hierarchy**
- Super Key → Candidate Key → Primary Key
- Foreign Key = Points to another table

### **Rule 3: Index Rules**
- Primary = One per table, orders file
- Secondary = Always dense, alternative path
- Dense = Every record, Sparse = Some records

### **Rule 4: SQL Types**
- DDL = Structure (CREATE, ALTER, DROP)
- DML = Data (SELECT, INSERT, UPDATE, DELETE)
- DCL = Permissions (GRANT, REVOKE)
- TCL = Transactions (COMMIT, ROLLBACK)

### **Rule 5: ACID**
- Atomicity = All or nothing
- Consistency = Valid states
- Isolation = No interference
- Durability = Permanent
