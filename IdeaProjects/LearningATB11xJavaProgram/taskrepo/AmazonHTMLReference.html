1️⃣ SEARCH BOX AREA

<div id="nav-search">
  <form id="nav-search-bar-form" method="get" action="/s">
    
    <!-- CATEGORY DROPDOWN -->
    <div id="nav-search-dropdown-card">
      <select id="searchDropdownBox" class="nav-search-dropdown" name="url">
        <option selected value="search-alias=aps">All</option>
        <option value="search-alias=electronics">Electronics</option>
        <option value="search-alias=books">Books</option>
      </select>
    </div>
    
    <!-- SEARCH INPUT -->
    <div class="nav-search-field">
      <input type="text" 
             id="twotabsearchtextbox" 
             name="field-keywords"
             placeholder="Search Amazon"
             autocomplete="off">
    </div>
    
    <!-- SEARCH BUTTON -->
    <div class="nav-search-submit">
      <input id="nav-search-submit-button" 
             type="submit" 
             value="Go"
             class="nav-input">
    </div>
    
  </form>
</div>
XPaths to Remember:
• Search Box: //input[@id='twotabsearchtextbox']
• Search Button: //input[@id='nav-search-submit-button']
• Category Dropdown: //select[@id='searchDropdownBox']

<div class="s-main-slot">
  
  <!-- EACH SEARCH RESULT -->
  <div data-component-type="s-search-result" 
       data-asin="B0ABC123"
       class="s-result-item">

      <a class="a-link-normal s-no-outline" href="/dp/B0ABC123">

      </a>
    </div>
    
    <!-- PRODUCT TITLE -->
    <h2 class="a-size-mini">
      <a class="a-link-normal s-underline-text" href="/dp/B0ABC123">
        <span class="a-text-normal">iPhone 15 Pro Max 256GB</span>
      </a>
    </h2>
    
    <!-- RATING -->
    <div class="a-row a-size-small">
      <span class="a-icon-alt">4.5 out of 5 stars</span>
      <span class="a-size-base">12,345</span>
    </div>
    
    <!-- PRICE -->
    <div class="a-row">
      <span class="a-price">
        <span class="a-offscreen">$1,199.00</span>
        <span class="a-price-symbol">$</span>
        <span class="a-price-whole">1,199</span>
        <span class="a-price-fraction">00</span>
      </span>
    </div>
    
  </div>
  
</div>
XPaths to Remember:
• All Results: //div[@data-component-type='s-search-result']
• First Result: (//div[@data-component-type='s-search-result'])[1]
• Product Titles: //h2//span[@class='a-text-normal']
• Prices: //span[@class='a-price-whole']
• Click Product: (//a[@class='a-link-normal s-no-outline'])[1]

6️⃣ PAGINATION

<div class="s-pagination-container">
  <span class="s-pagination-item s-pagination-previous s-pagination-disabled">
    Previous
  </span>
  
  <span class="s-pagination-item s-pagination-selected">1</span>
  
  <a class="s-pagination-item s-pagination-button" href="?page=2">2</a>
  <a class="s-pagination-item s-pagination-button" href="?page=3">3</a>
  
  <span class="s-pagination-item s-pagination-ellipsis">...</span>
  
  <a class="s-pagination-item s-pagination-button" href="?page=20">20</a>
  
  <a class="s-pagination-item s-pagination-next" href="?page=2">
    Next
  </a>
</div>
XPaths to Remember:
• Next Page: //a[contains(@class,'s-pagination-next')]
• Previous: //span[contains(@class,'s-pagination-previous')]
• Current Page: //span[contains(@class,'s-pagination-selected')]
• Page Number: //a[@class='s-pagination-item'][text()='5']

• Password: //input[@id='ap_password']

• All Suggestions: //div[contains(@class,'s-suggestion')]
• Specific Text: //div[@data-keyword='iphone 15 pro max']
• Contains: //div[contains(@class,'s-suggestion')][contains(.,'pro max')]
